208 """ 

209 Calculate stepped accessibility isochrones from origin objects over an urban 

210 graph, splitting each reachable area into concentric bands of width ``step``. 

211 

212 Unlike coverage, the search runs outward from the origins (along the original 

213 edge direction on a directed graph). The function: 

214 

215 1. Snaps each origin to its nearest graph node (or uses the provided 

216 ``origin_nodes``). 

217 2. Runs a multi-source Dijkstra search outward from the origins. 

218 3. Buckets reachable nodes into steps and builds banded geometry with the 

219 selected ``geometry_type``. 

220 4. Optionally clips the bands to ``zone``. 

221 

222 Args: 

223 urban_graph: 

224 City graph with node and edge tables. 

225 

226 gdf_origins (gpd.GeoDataFrame, optional): 

227 Origin objects. If the table contains ``graph_node_column`` those ids 

228 are used; otherwise geometries are snapped to nearest nodes. Pass 

229 either this or ``origin_nodes``. 

230 

231 origin_nodes (Iterable, optional): 

232 Ready-made origin node ids, used instead of ``gdf_origins``. 

233 

234 graph_node_column: 

235 Name of the graph node id column in ``gdf_origins``. 

236 

237 weight_type: 

238 Type of edge weight used for path calculation: 

239 

240 - ``"time_min"``: time-based accessibility in minutes 

241 - ``"length_meter"``: distance-based accessibility in meters 

242 

243 geometry_type: 

244 Method used to build each step's geometry: 

245 

246 - ``None``: Voronoi cells around graph nodes 

247 - ``"radius"``: Voronoi cells clipped to residual-radius buffers 

248 - ``"ways"``: Voronoi cells clipped to buffered road geometry 

249 (walk edges only on intermodal/walk graphs) 

250 - ``"separate"``: independent circular buffers per step 

251 

252 weight_value_cutoff (float, optional): 

253 Maximum travel time or distance. If ``None``, the isochrone is built 

254 out to the farthest reachable node. 

255 

256 zone (gpd.GeoDataFrame | gpd.GeoSeries, optional): 

257 Boundary polygon to clip the resulting stepped isochrones. 

258 

259 step (float, optional): 

260 Width of each step, in units of ``weight_type``. Defaults to 

261 100 meters for ``length_meter`` and 1 minute for ``time_min``. 

262 

263 buffer_factor: 

264 Residual-radius multiplier for geometry construction (default 0.7). 

265 

266 road_buffer_size: 

267 Edge buffer for ``geometry_type="ways"``, in meters (default 5.0). 

268 

269 Returns: 

270 gpd.GeoDataFrame: 

271 Stepped isochrone polygons with a ``dist`` column (the upper bound of

273 the CRS of ``gdf_origins`` (or the graph CRS). 

274

278 its nearest origin).

281 waits for the vehicles that call there.
